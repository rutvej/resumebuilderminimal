# 🚀 OpenResume Studio (PWA) - Free AI Resume Builder & Visual Fit Studio

**OpenResume Studio** is a 100% free, zero-maintenance, serverless Progressive Web App (PWA) designed to build pixel-perfect resumes. It runs entirely in the browser and can be deployed instantly to **GitHub Pages**.

---

## ✨ Key Architectural Highlights

1. **100% Free & Zero Server Costs ($0 Forever)**:
   - Hosted for free on GitHub Pages as a static application (`index.html`).
   - No Cloudflare Workers, no API proxies, no database dependencies, no rate limits, and zero developer liability.
2. **Offline-First PWA (Service Worker Cached)**:
   - Installable on mobile phones (Android / iOS) and desktop via **"Add to Home Screen"**.
   - Opens and functions 100% offline in airplane mode.
3. **Delegated AI Content Engine (1-Tap ChatGPT / Claude Bridge)**:
   - Generates an **Agentic System Contract Prompt** that you can copy to free ChatGPT or Claude.
   - ChatGPT outputs a structured `<RESUME_JSON>` payload.
   - **1-Tap Ingest**: Paste the response back into the app, and your entire resume updates automatically!
4. **Visual Fit-to-1-Page Controls (What LLMs Cannot Do)**:
   - Live font size slider (`10px` to `16px`).
   - Line height & section spacing sliders to eliminate 1-page overflow in seconds.
   - Accent color swatches and typography selectors (Inter, Outfit, Merriweather, JetBrains Mono).
5. **Dynamic LLM Template Import**:
   - Paste custom HTML templates generated by ChatGPT from resume photos/sketches.
6. **Pixel-Perfect PDF Export**:
   - Uses browser-native `@media print` rules for clean, A4-formatted PDF downloads.

## 🛠️ How to Deploy to GitHub Pages (1-Click Setup)

1. **Create a GitHub Repository**:
   - Push all files in this directory (`index.html`, `manifest.json`, `sw.js`, `README.md`) to a GitHub repository (e.g. `your-username/resume-builder`).
2. **Enable GitHub Pages**:
   - Go to your repository settings on GitHub: `Settings` -> `Pages`.
   - Under **Build and deployment**, set **Source** to `Deploy from a branch`.
   - Select `main` branch and `/ (root)` folder. Click **Save**.
3. **Done!**:
   - Your PWA will be live at `https://your-username.github.io/resume-builder/`.

## 📱 Installing on Mobile Phones (Android / iOS)

* **Android (Chrome)**: Open the site, tap the three dots `⋮`, and select **"Add to Home screen"** or **"Install app"**.
* **iOS (Safari)**: Open the site, tap the Share button `⎘`, and select **"Add to Home Screen"**.

## 🧠 How the 1-Tap ChatGPT / Claude Agentic Bridge Works

```
1. Paste Job Description (optional) into the LLM Assistant tab.
2. Click "🚀 Copy Prompt for ChatGPT / Claude".
3. Open ChatGPT or Claude app, paste the prompt, and click Send.
4. Copy ChatGPT's output, return to the app, and click "✨ Apply Generated Resume".
5. Use the Font Size & Spacing sliders to fit your resume onto 1 page perfectly!
```
